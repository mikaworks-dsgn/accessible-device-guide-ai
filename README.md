# accessible-device-guide-ai

> 🚧 開発中です

発達障害のある人とその保護者に、タブレットやスマホの使い方の情報が「届く形」で伝わるようにするための、技術検証とサービス企画です。

## 背景

端末の使い方の情報は、教材やヘルプとしてたくさん公開されています。しかし、一度に多くの手順が書かれていたり、「しばらく」「適宜」のような曖昧な表現が使われていたりして、特性によっては理解しにくいことがあります。情報が「ある」ことと、その人に「届く」ことは別の問題です。

## このプロジェクトで確かめること

1. **現状分析**：公開されている使い方の教材は、発達特性のある人にとってどれくらい分かりにくいか
2. **AIによる改善**：教材をもとに、相手の特性に合わせて答えるAIを作る
   - 本人モード：最初に見通しを示し、一度に一つの手順だけを伝える
   - 保護者モード：設定や見守り、本人への伝え方を中心に答える
3. **検証**：AIの回答は分かりやすくなったか。内容は元の教材と食い違っていないか
4. **サービス企画**：検証結果をもとに、タブレットと使い方サポートをまとめたサービスを考える

## 技術構成

| 技術 | 使い道 |
|---|---|
| Python / pandas | 教材テキストの整形と集計 |
| janome | 日本語の単語分割 |
| scikit-learn | 分析の補助 |
| Amazon Bedrock | LLM（Amazon Nova 2 Lite）とEmbedding |
| Jupyter Notebook | 分析の過程と結果の記録 |
