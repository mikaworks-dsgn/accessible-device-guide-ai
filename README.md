# accessible-device-guide-ai

> 🚧 開発中です

発達障害のある人とその保護者が、やりたいことに合うアプリにたどり着き、その使い方を自分の特性に合った形で知るための、技術検証とサービス企画です。

## 背景

やりたいことがあっても、どのアプリを使えばよいか分からなければ、サービスにたどり着けません。また、アプリが分かっても、使い方の説明が一度に多くの手順を含んだり、曖昧な表現を使ったりすると、特性によっては理解しにくいことがあります。アプリを選ぶところから、使い方を理解するところまでを支援します。

## このプロジェクトで確かめること

1. **アプリカタログ作成**：パックに入っている約10個のアプリについて、名前・できること・開き方などを独自にまとめる
2. **案内役の検証**：利用者の「やりたいこと」（例：映画が見たい）から合うアプリを選び、その使い方を特性に合わせて案内する
3. **2つの観点で検証**
   - やりたいことの質問から、正しいアプリに案内できた割合
   - 回答が、特性に合わせた伝え方のルールを守れているか
4. **教材分析（任意）**：時間があれば、デジタル活用支援の教材を1講座だけ分析する
5. **サービス企画**：検証結果をもとに、タブレットと使い方サポートをまとめたサービスを考える

各社のヘルプ文章は使わず、アプリの説明は独自に作成します。著作権に配慮し、知識源を自作のアプリカタログに限定します。

## 技術構成

| 技術 | 使い道 |
|---|---|
| Python / pandas | アプリカタログや検証結果の整理・集計 |
| janome | 日本語の形態素解析 |
| scikit-learn | 自然言語処理・分析の補助 |
| Amazon Bedrock | LLM（Amazon Nova 2 Lite）とEmbeddingによる案内・意味検索 |
| Jupyter Notebook | 検証の過程と結果の記録 |
