# 正解をつけるときの判定基準

評価用の文に正解をつけるときの基準です。研究で質的データを分類するときの「コーディングマニュアル」にあたります。
基準を決めておくことで、文によって判断がぶれないようにします。
例は評価用の30文（`data/eval_sentences.csv`）から取り、確認用の文（`data/holdout_sentences.csv`）とは重ねません。

## 方向

| 判定 | 基準 | 例 |
|---|---|---|
| 新しいこと | まだやったことがないこと、いつもと違うことを求めている | 新しい、知らない、非日常、「〜てみたい」 |
| いつものこと | 前に経験したことや、慣れたことを求めている | いつもの、しばらく行っていない（前に行って良いイメージがある） |
| どちらでも | 本人がどちらでもよいと言っている | 何でもいい |
| 不明 | 手がかりがない | 「面白いことしたい」「贅沢したい」 |

- 「〜てみたい」は、試しにやるという意味で、新しいことへの興味を表すものとする（2026-10-08）
- 対象を知っていても、その中でまだやったことがないことなら「新しいこと」とする

## 具体性（基準2：2026-10-08 決定）

| 判定 | 基準 | 例 |
|---|---|---|
| 高い | 具体的な場所・物・作品まで決まっている | 具体的な店名や作品名が入っているもの |
| 中くらい | やることや行き先の種類は分かるが、どれかは決まっていない | 「行ったことのない街を歩き回る」「面白そうな展示を見に行く」「いつも読んでいるジャンルの本」、作る、外に出る |
| 低い | 何をするか決まっていない | 「なんか面白いこと」「めちゃくちゃ遊びたい」 |

- 「ぶらぶら」などがあっても、行き先の種類が分かれば「中くらい」とする（例：「知らない場所にふらっと行ってみたい」）

## 人との関わり

| 判定 | 基準 | 例 |
|---|---|---|
| 一人で | 一人ですることを求めている | 一人で、没頭 |
| 誰かと | 相手がいることを求めている | 友達と、みんなで、少人数、文末の「ね」で笑い合う相手を感じる |
| どちらでも | 本人がどちらでもよいと言っている | 誰とでも |
| 不明 | 一人でも誰かとでも成り立つ、または手がかりがない | 「いろいろな人の考えていることを知りたい」 |
